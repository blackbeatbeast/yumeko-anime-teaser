# ゆめこ、今日も創作中。

既存のアニメ風ティザーを、AI/Codexとつくった4作品の紹介へ更新したローカル草案です。

- BookVoice：本の段落再生、地の文・台詞の声分け。開発ベータ。
- AINE：AIとのメッセージ・音声会話、会話の整理と分岐。
- 育児ログ：スマホで記録し、時刻順の紙ビューから書き写すPWA。
- IrodoriMicBridge：マイクの文字起こしからIrodoriTTSと仮想音声出力へつなぐツール。

元のキャラクター素材、ヒーローの構図、紙色・ピンク・黄色・紫、黒い枠と影、斜めの額縁、動く帯、ぬボタンを維持しています。ゲーム・配信紹介と創作エピソードは、4作品と制作過程に置き換えました。

## ローカル確認

Node.js 22.13以降。

```text
npm ci
npm run build:pages
npm run preview:pages
```

http://127.0.0.1:4382/yumeko-anime-teaser/ で草案を確認できます。ローカルの静的ファイルだけを配信し、アプリ本体やデータベースへ接続しません。

## デモ素材

`public/demos/` の4本は、実際のUIを隔離環境で描画し、そのスクリーンショットをつないだ13秒の紹介用アニメーションです。架空の短編、会話台本、育児記録、デバイス名だけを使い、音声は含みません。

- BookVoice：実際のHTML/CSS/操作スクリプト。本文領域に独自短編を配置し、ページ範囲・台詞設定を操作。再生エンジンは起動しません。
- AINE：実際のReactコンポーネントとスタイル。新しいブラウザ領域で架空の相手・会話を使い、既存デモモードへ台本の返答を渡します。Electron・AI・音声には接続しません。
- 育児ログ：既存のPreviewWorkspaceと同じ操作画面。架空の記録をメモリ内で保存し、紙ビューへ切り替えます。Firebase初期化コードはコピーせず、認証・DB呼び出しを無効化しています。
- MicBridge：実際のTkウィジェット生成コードだけを抽出。架空の文章と話者を表示し、出力モードの選択を紹介。サービス・モデル・デバイス列挙・グローバルホットキーは起動しません。

各作品にMP4（H.264）、WebM、WebPポスター、3枚の拡大用静止画、日本語VTTを用意しています。中央付近に来た作品1本だけを無音で自動再生し、対象外・別タブでは停止します。手動停止は同じ表示位置で維持し、完全に画面外へ出て戻ったときに再開。動き低減設定では自動再生しません。通常の再生操作・シーク・全画面も使えます。縦画面・横画面それぞれの比率を保持。テキスト説明、再生失敗時の静止画を含みます。

元アプリのコードを読み取り専用で参照し、元のデータ・設定・起動プロセス・個人の声・モデル・アカウントは変更していません。非公開のアプリソースはGit対象外の `work/real-ui/` だけに保持し、サイトのビルドや配布には含めません。非公開リポジトリや利用者固有のURLは紹介に含めません。MicBridgeの公開ソースだけへリンクします。

ぬボタンからは色違いの「＼ぬ／」が飛び、揺れながら落ちます。表示は最大72個、終了時に削除。重ねた演出は操作を遮らず、動き低減設定では静かな一言だけを表示します。

## 検証

`npm run build:pages`、`npx tsc --noEmit`、変更したアプリコードのoxlintが成功。専用の一時Chromeで320/390/768/1440pxの表示、水平はみ出し、ページエラー、4本の再生とシーク、Range応答、同時再生の停止、ぬボタンの連打・終了後の削除、キーボード操作、動き低減を確認しました。

動画のキーボード再生/停止、MP4が読めないときのWebM切り替え、両形式が読めないときの縦比率を保った静止画表示、拡大リンク16個のHTTP 200も確認。連続したぬ演出中も動画が進み、演出終了後の粒子数は0です。BookVoiceとAINEの主要UI/スタイル5ファイルは、元ソースとコピーのSHA-256が一致しています。画面素材28ファイルの合計は約1.84 MiBです。

1440/390pxで4作品を順に中央へ移し、常に1本だけの無音再生になること、画面外で停止すること、手動停止が維持されること、再入場と手動再生で再開できることを確認。動き低減・ブラウザーによる再生拒否も検証しています。別タブ停止/復帰は、ヘッドレスChromeの可視性制約があるため `visibilitychange` と非表示状態を模擬して確認しています。

スクリーンショットと結果はGit対象外の `outputs/review/`。公開中Pagesの変更前画像も撮影しています。実iPhone/Safariや実アプリの機能テストは実施していません。

全体lintには、未使用のスターター同梱UI/hooksの既存指摘があります。今回は変更したアプリコードを検査しています。

## 素材の再生成と検証スクリプト

通常ビルドには不要です。専用作業ディレクトリにツールを準備した環境で使います。

```text
npm install --prefix work/qa --no-save playwright ffmpeg-static
```

安全に隔離した実UIから撮影済みのPNGを `work/real-ui/screens/` に置き、`node scripts/assemble-real-ui-demos.mjs` で配信用素材を生成できます。隔離用のアプリコピー・アダプターは公開ソースには含めません。古い概念デモの生成スクリプトは削除しています。

ローカルプレビューを起動して `node scripts/verify-showcase.mjs` で表示・動画・ぬ演出を、`node scripts/verify-demo-playback.mjs` でスクロール再生・手動停止・再入場・別タブ・動き低減・再生拒否を確認できます。公開サイトの変更前スクリーンショットは既存のものを保ち、再取得する場合だけ `CAPTURE_PUBLIC_BASELINE=1` を設定します。TypeScriptの対象から一時アプリコピーが入った `work/`、検証成果物の `outputs/`、ビルド出力を除外しています。
